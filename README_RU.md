<h1 align="center">YT Music → Last.fm → Telegram</h1>

<p align="center">

Приложение получает `nowplaying` из Last.fm, создаёт Telegram-аудио с корректными метаданными и либо добавляет его в музыку профиля, либо временно публикует в выбранном личном канале. Источником прослушивания может быть YouTube Music в браузере, Android-приложение или любой проигрыватель со скробблингом в Last.fm.

> [!IMPORTANT]
> Это не Telegram-бот. Bot API не умеет изменять музыку пользовательского профиля, поэтому приложение локально авторизуется как ваш Telegram-клиент через Telethon. Никому не передавайте файл `telegram.session`.

## Как это работает

```mermaid
flowchart LR
    YT[YouTube Music] --> S[Web Scrobbler<br>или Pano Scrobbler]
    S --> LF[Last.fm<br>nowplaying]
    LF --> APP[YT Music<br>Telegram Sync]
    APP --> SM[Saved Messages]
    SM --> TG[Telegram<br>Music on Profile]
    APP --> CH[Публичный канал<br>текущий трек]
```

Приложение:

- читает только активный `nowplaying`, а не последний завершённый scrobble;
- фильтрует кратковременные пропадания статуса несколькими проверками;
- работает в системном трее без окна на панели задач;
- публикует placeholder либо настоящий MP3 с названием, исполнителем и обложкой;
- хранит ограниченный LRU-кэш и восстанавливает его после перезапуска;
- очищает добавленные за сессию треки после остановки прослушивания;
- умеет ставить emoji status Telegram Premium на время `nowplaying` и возвращать прежний;
- может временно назначать выбранный публичный канал личным каналом профиля, публиковать там только текущий трек и восстанавливать прежний канал;
- поддерживает русский и английский интерфейс окна настройки и системного трея;
- позволяет отключить уведомления трея либо оставить их без звука;
- поддерживает паузу, ручную синхронизацию и очистку из меню трея;
- не хранит пароль Last.fm, код Telegram и пароль Telegram 2FA.

## Быстрый старт

### Требования

- Windows 10 или 11;
- Python 3.11 или новее; рекомендуемая версия — Python 3.12 x64;
- аккаунты [Last.fm](https://www.last.fm/) и Telegram;
- [Last.fm API key](https://www.last.fm/api/account/create);
- Telegram `api_id` и `api_hash` с [my.telegram.org/apps](https://my.telegram.org/apps);
- скробблер для передачи YouTube Music в Last.fm;
- FFmpeg только для режимов `mixed` и `audio`.
- Telegram Premium только для автоматической смены emoji status.
- собственный или администрируемый публичный broadcast-канал для канального режима; группы и супергруппы не поддерживаются Telegram API.

### Установка

Скачайте репозиторий, откройте PowerShell в его каталоге и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
```

Скрипт найдёт установленный совместимый Python, создаст `.venv`, установит приложение и откроет мастер настройки. Если Python отсутствует, но доступен `winget`, скрипт предложит установить Python 3.12. Дальше:

1. Выберите **Русский** или **English** в правом верхнем углу.
2. Введите Last.fm username и API key.
3. Нажмите **Проверить Last.fm**.
4. Введите Telegram API ID, API hash и телефон в международном формате.
5. Нажмите **Отправить код**, затем введите код Telegram.
6. Если включена 2FA, введите её пароль — он используется только для входа.
7. Выберите назначение музыки: **Профиль**, **Личный канал** или **Профиль + канал**.
8. При необходимости выберите emoji status — он работает в обоих режимах. Для канального режима также нажмите **Выбрать…** рядом с каналом и выполните подсказку в Telegram.
9. Проверьте остальные параметры, выберите режим аудио и настройки уведомлений, затем нажмите **Сохранить**.

При первой установке окно закроется — после этого откройте `start_tray.vbs`. Если настройки были открыты из трея, после сохранения приложение автоматически перезапустится с новым конфигом. Крестик также сохраняет валидные изменения; **Отмена** закрывает окно без сохранения.

> [!NOTE]
> Для API требуется Last.fm username, а не email. Username виден в адресе профиля: `last.fm/user/USERNAME`.

## Передача YouTube Music в Last.fm

В браузере установите [Web Scrobbler](https://webscrobbler.com/), подключите Last.fm и разрешите работу на `music.youtube.com`.

На Android можно использовать официальное приложение Last.fm или Pano Scrobbler. На iOS внешний скробблинг из штатного YouTube Music ограничен; практический вариант — YouTube Music в Safari с совместимым скробблером.

Перед запуском синхронизации откройте свой профиль Last.fm и убедитесь, что рядом с треком отображается **Scrobbling now**.

## Режимы аудио

| Режим | Поведение | FFmpeg | Когда выбирать |
|---|---|:---:|---|
| `placeholder` | Мгновенно публикует короткий беззвучный MP3 с метаданными и обложкой | Нет | Самый быстрый и надёжный режим |
| `mixed` | Сразу публикует placeholder, затем в фоне заменяет его найденным аудио | Да | Лучший баланс скорости и настоящего звука |
| `audio` | Сначала скачивает аудио и только после этого публикует трек | Да | Когда placeholder вообще не нужен |

Для `mixed` и `audio` установите FFmpeg:

```powershell
winget install --id Gyan.FFmpeg -e
ffmpeg -version
```

Аудио ищется через `yt-dlp` по исполнителю и названию. Last.fm не передаёт исходный YouTube `videoId`, поэтому иногда может быть выбрана другая версия, ремикс или концертная запись. При ошибке поиска приложение использует placeholder.

> [!WARNING]
> Скачивание и повторная публикация аудио могут регулироваться условиями сервиса и авторским правом вашей юрисдикции. Пользователь самостоятельно отвечает за использование режимов `mixed` и `audio`.

## Запуск

### Системный трей

Откройте `start_tray.vbs`. Приложение запустится через `pythonw.exe`: без консоли и без кнопки на панели задач. Значок может находиться за стрелкой `^` в области уведомлений.

Из меню трея можно:

- приостановить или возобновить синхронизацию;
- немедленно проверить Last.fm;
- очистить созданную приложением музыку профиля;
- удалить текущую публикацию приложения из канала;
- изменить настройки;
- открыть журнал или каталог данных;
- перезапустить или завершить приложение.

### Диагностическая консоль

```text
start_console.bat
```

Остановка — `Ctrl+C`.

### Автозапуск Windows

1. Нажмите `Win+R`.
2. Введите `shell:startup`.
3. Создайте в открывшейся папке ярлык на `start_tray.vbs`.

## Настройки синхронизации

| Параметр | Назначение |
|---|---|
| Язык | Переключает окно настройки сразу; после сохранения этот же язык используется в меню и уведомлениях трея |
| Опрос Last.fm | Интервал запросов; рекомендуется 5–10 секунд, минимум — 3 |
| Проверок перед idle | Число пустых ответов перед подтверждением остановки; рекомендуется 3 |
| Треков в профиле | Максимальный размер LRU-кэша |
| Параллельных загрузок | Число фоновых загрузчиков для режима `mixed` |
| Куда отправлять музыку | `Профиль` сохраняет треки в Music on Profile; `Личный канал` публикует только текущий трек в канале; `Профиль + канал` делает и то и другое без повторного скачивания |
| Канал для nowplaying | ID публичного broadcast-канала; кнопка **Выбрать…** считывает его из настроек профиля Telegram |
| Emoji status при nowplaying | Галочка включает автоматическую смену статуса; выбранный custom emoji ID сохраняется и не теряется при отключении |
| Удалять музыку при idle | После подтверждённой остановки снимает с профиля все отслеживаемые треки сессии |
| Показывать системные уведомления | Управляет уведомлениями о треках, ошибках, очистке и настройках из приложения в трее |
| Воспроизводить звук уведомлений | Оставляет уведомления видимыми, но при отключении передаёт Windows флаг `NIIF_NOSOUND` |

Last.fm не предоставляет отдельное событие `stop`, поэтому очистка происходит после исчезновения `nowplaying` и заданного количества пустых проверок.

Галочка **Emoji status при nowplaying** явно включает или отключает функцию, не удаляя выбранный ID. Кнопка **Выбрать…** проверяет Telegram Premium, запоминает текущий статус и просит установить в Telegram обычный emoji status для прослушивания. Считав его ID, мастер сразу возвращает исходный статус. Во время работы выбранный emoji устанавливается при активном `nowplaying`, а прежний возвращается после подтверждённого idle, паузы или штатного завершения приложения. Если во время прослушивания изменить статус вручную, приложение сохранит это изменение.

В режиме **Личный канал** мастер аналогично просит временно выбрать канал через **Telegram → Изменить профиль → Личный канал**, считывает его ID и возвращает исходный канал. При `nowplaying` приложение назначает выбранный канал личным, публикует в нём один актуальный аудиопост и удаляет предыдущий при смене трека. После подтверждённого idle, паузы или штатного выхода пост удаляется, а прежний личный канал восстанавливается. Музыка при этом не добавляется в Music on Profile и Saved Messages не используется. Emoji status можно независимо включить и для этого режима. Ручные изменения личного канала и emoji status во время прослушивания не перезаписываются.

Режим **Профиль + канал** использует один подготовленный аудиофайл для обоих назначений: треки сохраняются в Music on Profile по правилам LRU-кэша, а в канале остаётся только текущая публикация. При idle канальный пост удаляется всегда, а музыка профиля — только если включена настройка **Удалять музыку профиля, когда nowplaying исчез**.

## Данные и безопасность

Все пользовательские данные хранятся вне репозитория:

```text
%APPDATA%\YTMusicTelegramSync\
├── config.json          # настройки и API-реквизиты
├── config.draft.json    # черновик незавершённой первичной настройки
├── state.json           # сообщения, созданные приложением
├── telegram.session     # авторизованная Telegram-сессия
└── logs\app.log         # ротируемый журнал
```

Пароль Last.fm не нужен. Код Telegram и пароль 2FA не записываются. Фильтр журнала скрывает Last.fm API key из ошибок HTTP.

API key, API hash и номер телефона в окне настройки по умолчанию скрыты; показать их можно переключателем **Показывать реквизиты**. Никогда не публикуйте:

- `telegram.session` и `*.session-journal`;
- `config.json` и `config.draft.json`;
- скриншоты с открытыми реквизитами;
- API key, API hash, номер телефона и фрагменты журнала с персональными данными.

Эти файлы уже исключены через `.gitignore`.

## Решение проблем

<details>
<summary><strong>Last.fm показывает историю, но Telegram не обновляется</strong></summary>

Убедитесь, что трек имеет активный статус `nowplaying`, а не только появился в истории. Переподключите скробблер к Last.fm и проверьте разрешение для `music.youtube.com`.
</details>

<details>
<summary><strong>После паузы музыка остаётся в Telegram</strong></summary>

Приложение ждёт исчезновения `nowplaying` и несколько пустых ответов. При стандартных настройках очистка занимает около 15 секунд плюс возможная задержка самого скробблера.
</details>

<details>
<summary><strong>Режим mixed не заменяет placeholder</strong></summary>

Проверьте `ffmpeg -version`, доступ к YouTube и `%APPDATA%\YTMusicTelegramSync\logs\app.log`. Если аудио найти не удалось, placeholder намеренно остаётся в профиле.
</details>

<details>
<summary><strong>Telegram-сессия больше не авторизована</strong></summary>

Откройте **Настройки** из меню трея, повторно запросите код и выполните вход. После сохранения приложение перезапустится автоматически.
</details>

<details>
<summary><strong>Значка нет в трее</strong></summary>

Проверьте скрытые значки под стрелкой `^`. Если процесс завершился, запустите `start_console.bat` и посмотрите сообщение об ошибке.
</details>

<details>
<summary><strong>Установщик сообщает, что подходящая версия Python не найдена</strong></summary>

Разрешите `setup.ps1` установить Python, когда появится соответствующий вопрос, либо установите его вручную и повторите запуск:

```powershell
winget install --id Python.Python.3.12 -e
```

После ручной установки Python откройте новое окно PowerShell и снова запустите `setup.ps1`.
</details>

<details>
<summary><strong>После аварийного завершения остался emoji прослушивания</strong></summary>

Предыдущий emoji status хранится в памяти, чтобы приложение никогда не перезаписывало ручное изменение из другого клиента Telegram. Поэтому при принудительном завершении процесса автоматическое восстановление может не выполниться: очистите или измените статус в Telegram и затем запустите приложение обычным способом.
</details>

<details>
<summary><strong>После аварийного завершения остался музыкальный личный канал</strong></summary>

Предыдущий личный канал, как и emoji status, хранится только в памяти, чтобы не перезаписать ручное изменение из другого клиента Telegram. После принудительного завершения верните канал вручную в настройках профиля. Оставшийся аудиопост будет удалён после следующего подтверждённого idle, если приложение снова запущено с тем же канальным режимом.
</details>

## Разработка

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m mypy src
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Единственный источник версии приложения — `yt_music_telegram_sync.__version__`. Версия также отображается через `--version`, в окне настройки и подсказке значка трея. Для подготовки и публикации релиза из чистого рабочего дерева:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\release.ps1 -Version 1.2.0 -Push
```

Каждый успешный push в `main` запускает release workflow и создаёт prerelease с уникальным тегом вида `v1.1.0-build.5.1`. Перед публикацией выполняются все проверки, собираются wheel и ZIP с исходниками.

Для стабильного релиза используйте команду выше: скрипт при необходимости создаст release-коммит, стабильный тег `v1.2.0` и отправит их в GitHub. Push стабильного тега также запускает release workflow, но публикует обычный GitHub Release вместо prerelease. Подробности находятся в [CONTRIBUTING_RU.md](CONTRIBUTING_RU.md) и [CONTRIBUTING.md](CONTRIBUTING.md).

Структура проекта:

```text
src/yt_music_telegram_sync/  приложение и CLI
tests/                       модульные и регрессионные тесты
.github/workflows/           Windows CI для Python 3.11–3.14
setup.ps1                    установка и первичная настройка
release.ps1                  версия, проверки, тег и необязательный push
start_tray.vbs               тихий запуск в системном трее
start_console.bat            диагностический запуск
```

Правила для изменений описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
